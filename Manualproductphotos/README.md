# Product photos

Keep product images in this folder and use lowercase, hyphen-separated filenames that describe the product:

- `pvc-material.jpg` — PVC material
- `light-fitting-material.jpg` — light-fitting material
- `electrical-material.jpg` — general electrical material
- `motor-rewinding.webp` — motor rewinding

For new products, use the same pattern, such as `product-name.jpg`, then update that product's image path in `index.html`. Keep the file extension in the path identical to the image file.
